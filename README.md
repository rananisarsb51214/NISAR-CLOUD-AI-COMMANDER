# NISAR-CLOUD-AI-COMMANDER
AI-powered social media automation platform for YouTube, Facebook and Instagram. Multi-agent orchestration, AI content generation, scheduling, analytics, Firebase and Google Cloud integration.
NISAR CLOUD AI COMMANDER

AI-Powered Social Media Automation Platform

Build Smarter. Create Faster. Grow Better.

NISAR CLOUD AI COMMANDER is an AI-powered social media automation platform designed to centralize content creation, publishing workflows, scheduling, analytics and digital marketing operations across YouTube, Facebook and Instagram.

The platform uses a modular multi-agent architecture powered by Claude AI, Firebase and Google Cloud technologies.

«Project status: Development / Phase 1 planned. Deployment and platform integrations are not yet verified.»

⚙️ Installation

Requirements:

- Node.js LTS
- npm
- Firebase CLI
- Git

Clone the repository:

git clone YOUR_REPOSITORY_URL
cd nisar-cloud-ai-commander

Install dependencies:

npm install

Configure environment variables using ".env.example" as a template.

Start the development server using the project's configured script:

npm run dev

🧪 Testing

Run configured validation scripts:

npm run lint
npm run typecheck
npm test

Only report tests as passing when they have actually executed successfully.
